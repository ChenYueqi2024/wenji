问迹 0.5.1-preview：多个模型供应商与清晰的使用引导

先分清两件事
0.4 APK 在手机内运行资料处理、词项检索、引用校验、学习记录和固定案例规则。无需电脑服务、Python 安装或 ADB 端口转发。
通用 AI 解释仍由用户配置的远程模型服务提供，需要可用网络与个人 API Key；安装包没有内置通用大模型。
APK 支持 Android 8.0（API 26）及以上、具有 64 位 arm64-v8a 或 x86_64 运行环境的设备。本次版本为 v0.5.1-preview（versionCode 9），交付与验证状态以本版本记录为准。

三步离线体验
1. 在手机安装 APK 并打开问迹，保持默认规则演示模式。
2. 在资料页点击“导入内置合成教材”，导入 APK 自带的两页资源分配图 PDF；不需要下载资料。
3. 记录“资源分配图有环，是否一定死锁？”，查找依据并核对原文、页码和版本；进入复习，先独立作答，再查看参考关键点与自评。
默认规则仅覆盖这个合成教学案例，不提供通用问题的模型回答。文本或可复制文本 PDF 的导入、资料修订、撤回、查看引用与学习记录均在手机本地处理。

在应用内配置模型
1. 点击首页“添加或选择模型/供应商与模型”，或右上角“配置模型/切换模型”。管理页按“添加供应商→添加模型→选择使用”组织；宽屏显示左侧供应商列表，窄屏从列表进入详情。
2. 点击“添加供应商”，填写可识别的名称、API 基址、下列四种协议之一和个人 API Key。基址是 API 根路径，不是完整操作路径；不得包含用户名、密码、查询参数或片段。远程地址必须使用 HTTPS。
3. 在供应商下“添加模型”，填写实际模型 ID 和最大输出 Token（默认 2048，范围 1 至 16384；模型自身可能有更小上限）。一个供应商可保存多个模型。名称匹配只提供官方参数参考，不自动修改实际模型名或请求参数。
4. 点击“使用此模型”明确选用；新增供应商或模型不会自动启用。保存与切换只验证和记录配置，不发送模型请求，也不证明端点已连通。生成前核对端点、模型、问题和发送范围，单次确认后才可能调用；证据解释没有检索到材料时仍不会联网。
5. 每个供应商保存一个独立 Key，同一服务的不同 Key 可分别建立供应商。编辑原供应商且 API 基址不变时，密钥留空沿用原 Key；更换地址必须重输 Key。新供应商不会从其他供应商借用 Key。重新打开设置不回填密钥。
6. 选择“暂停模型，使用离线案例”保留所有配置。删除当前供应商或当前模型后转离线，不自动切到另一个供应商。删除供应商同时删除它的加密 Key 和模型列表，保留学习资料与历史答案；删除某个模型保留所属供应商的 Key。
设置错误固定显示在标题区域。非密钥草稿可保留旋转状态；未保存的 Key 只在内存，关闭或旋转后需重输。最多保存20个供应商、每个40个模型，不包含配置文件批量导入、密钥轮换池或自动查询远端模型列表。
额外请求头和协议兼容开关仍属于下方的电脑开发配置，不会自动同步到手机。

协议与根路径
openai_chat：根路径后追加 /chat/completions；适用于兼容该文本生成结构的服务。
openai_responses：根路径后追加 /responses；须支持 Responses 文本输出结构。
anthropic_messages：根路径后追加 /messages；固定 anthropic-version 为 2026-10-21，使用该版本支持的 Bearer 认证。
gemini_generate_content：根路径后追加 /models/{模型名}:generateContent；model 填写裸模型 ID，不加 models/ 前缀；使用 x-goog-api-key 请求头。
协议适配不等于任意供应商 API 都兼容。专有签名、特殊请求或响应、工具专用接口、流式专用服务需要新增适配器。当前不自动发现模型列表，不支持多模态或工具调用。
手机的 HTTP 地址仅允许 localhost/127.0.0.1/::1，指向手机自身，不是电脑。普通远程模型应使用供应商提供的 HTTPS 基址。

密钥、记录与升级
个人密钥由 Android Keystore 支持的 AES/GCM 加密，保存在应用私有存储。配置内容也参与加密认证；读取设置或配置引擎时，密钥会解密到进程内存，不进入公开状态、Room 学习缓存或源码。真实个人密钥不包含在 APK 中。
0.5.0暂停转离线会保留配置，仅明确删除供应商才移除该条目及其加密密钥。旧版单配置首次读取会在认证成功后原子迁移为一个供应商和模型，并保留当前选用。配置损坏或无法解密时显示错误，不自动清空或静默换用其他模型；保留应用数据排查。
升级到 0.4 后使用新的手机学习空间。电脑上的资料和旧手机 Room 数据仍保留，不自动迁移，也不会重放旧电脑版待发送请求。需要的资料可以重新导入；旧学习记录目前没有自动迁移入口。手机模型设置需重新填写，不读取电脑私有配置或环境变量。
手机 SQLite 保存资料、解释、引用与学习记录，新的 Room 数据库保存待处理操作和缓存。暂无账户或跨设备同步。

两种模式的区别
“查找依据”生成课程资料支持的解释：先导入相关文本或可复制文本 PDF，再查找依据。默认内置教材只有资源分配图与死锁，不能支撑“什么是强化学习”等其他主题。没有相关材料时提示待补材料，不证明网络或模型调用失败，也不会自动切换到通用回答。
“通用知识参考”从独立入口请求模型已有知识：需已配置模型并另行确认，只发送本次问题，不发送课程资料。结果与复习卡标注“尚无课程依据”，不添加页码或伪造引用；可先独立作答、对照模型参考并自评，不把这类自评当成课程结论已核验。
课后导入资料时先保存到本机，不自动上传。随后主动确认生成资料版解释；有充分依据并通过引用结构校验后，资料版答案与卡片优先显示，原通用答案、复习卡与历史作答继续保留并提示版本关系。资料不足或存在冲突时仍需补充核对，不能凭操作成功推断两版语义一致。
旧规则解释不会因保存模型设置自动更新；需要主动重新生成。通用参考也不会在刷新或应用重启时自动重新调用，问题修订后旧参考须重新核对。已有通用参考补建复习卡属于本地迁移，不消耗模型请求。

配置引导与模型能力提示
未配置模型时首次弹窗说明离线案例的局限，可选择去配置或先体验；首页长期保留显眼的模型设置按钮。
填写模型名后显示已核验官方型号的上下文（或输入上限）、最大输出和图像能力。第三方别名包含明确型号线索时可推荐最接近的已收录官方参数，匹配依据可展开查看。官方型号、官方版本候选与第三方别名候选分别标注；名称含混、变体不明确或多个型号冲突时不硬猜。
这些是静态官方规格参考，不是对当前服务的探测，不自动更改实际模型名称或输出Token。服务方可能限制上下文、输出和输入模态。问迹当前仅发送文本，即使模型支持图像/音频/视频，本版也不发送这些内容。

证据解释的发送范围与结果校验
证据解释时模型得到本次问题和词项检索命中的最多 8 个片段，合计最多 12000 字符；片段可能包含资料中的敏感内容，发送前须核对使用权、供应商与发送范围。原 PDF 文件和个人学习记录不随生成请求上传。
片段 ID 由手机内置引擎生成；模型不能指定来源路径、版本、页码或偏移。返回 JSON 只能含 status、claims 和 missing_information，结论须引用本次已有 ID。
JSON、引用归属及原文位置和版本校验均通过才保存。引用定位正确不证明结论得到原文的语义支持，仍需人工核对。
没有词项候选时直接保留待补材料，不发送模型请求。该证据解释分支在资料不足或冲突时不新建课程资料卡；用户仍可另行确认生成明确标注尚无依据的通用卡。模型不会将学生自动标记为已掌握。
生成期间不持有数据库锁；返回时再次检查问题、资料快照和配置，变化则丢弃结果。模型使用过的课程资料变化会保守地使整条解释与卡片进入待复核。撤回清理本机派生文本，无法撤回供应商已收到的内容。

中断、重试与费用
刷新与应用重启不会自动重发任何待处理的解释或通用参考请求。待处理记录会保留，同时读取本机最新状态。
发送模型请求前，引擎持久保留 request_id；已发送的同一请求不会通过重复请求再次调用供应商。
超时、认证失败、限流、格式不合法或应用中断后，先刷新检查是否已有结果。需要重新生成时，先“停止重试并核对状态”，再重新查找依据并单次确认。停止重试不会撤销已经生效的结果，也不能取消供应商已收到的调用；新请求可能再次计费。
错误响应不回显上游正文、请求头、密钥或本机文件路径。配置或模型失败不会以规则答案冒充模型成功。
手机配置的 timeout_seconds 为 60。它约束连接/读超时和正文读取截止检查，不保证 DNS、慢响应头等所有阶段的严格总时长。最大输出 Token 控制输出上限，不是精确费用预算。
HTTP 传输直接连接，不自动使用系统代理、不跟随重定向、不自动重试；需要端点在手机当前网络可达。

开发者可选：电脑服务与高级 JSON 配置
以下路径继续可用，但与 0.4 手机运行相互独立，不是安装或使用 APK 的前提。电脑服务使用自己的 data/wenji.sqlite3；修改它不会更改手机资料或手机模型设置。
在 runtime 目录执行（公开源码从仓库根目录执行）：
1. 复制 config/models.example.json 为 config/models.local.json。
2. 用 active_profile 选择档案，填写 protocol、base_url、model。
3. api_key_env 填写密钥的环境变量名，例如 WENJI_MODEL_API_KEY。真实密钥不写入 JSON、源码、截图或 Git；GitHub PAT 不能充当模型 API Key。
4. 停止旧的 8765 端口服务后运行：
   .\scripts\run_model_service.ps1
   若环境变量尚未设置，脚本以隐藏输入提示密钥，仅传给这次服务进程；退出后清理脚本临时设置的变量。
也可以先设置环境变量再运行：
   .\scripts\run_service.ps1 -ModelConfig .\config\models.local.json
恢复电脑规则模式：停止服务后运行 .\scripts\run_service.ps1，不指定 ModelConfig。电脑配置修改后需要重启该服务；手机内设置保存后在进程内生效。
电脑服务仅监听 127.0.0.1:8765，可用于开发与协议检查。0.4 APK 不连接该端口，不需要 ADB reverse。

电脑高级参数
auth_mode="none" 可用于无需认证的回环服务，不能配置 api_key_env，仅允许 localhost/127.0.0.1/::1；非回环地址必须 HTTPS 并配置密钥。
extra_headers 支持普通请求头；敏感头值使用 {"env":"WENJI_VENDOR_HEADER_KEY"} 引用用户预先设置的环境变量。传输或认证保留头不允许通过 extra_headers 覆盖。
auth_header 可选 bearer、x-api-key、api-key、x-goog-api-key；默认 Gemini 使用 x-goog-api-key，其余使用 Bearer。不能与 auth_mode="none" 混用。
openai_chat 的 compatibility 支持 chat_token_parameter（max_tokens 或 max_completion_tokens）、json_mode（默认 true）、send_store（默认 false，省略 store 字段；true 表示发送 store:false）。这些开关控制协议兼容性，不会开启对话存储；即使关闭 JSON 模式，响应仍须通过约定结构校验。
generation.max_output_tokens 默认 2048，范围 1 至 16384；temperature 可选 0 至 1，但固定的 Anthropic 2026-10-21 版本不接收它，配置后会被拒绝。
timeout_seconds 默认 30，范围大于 0 且不超过 60，具有与手机相同的超时边界。供应商可能限制参数组合，以其官方文档为准。
