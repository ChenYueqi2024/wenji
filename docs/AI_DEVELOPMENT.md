# AI 开发协作说明

更新至 v0.5.1-preview，2026-11-17。本文记录实际协作范围，不是完整会话导出，也不证明任何人独立完成、审查或理解全部代码。

## 需求与实现的分工

用户确定“问迹”的方向、匿名要求、引用可追溯、资料变更失效与先独立作答等原则，提供现有计划书、MuMu 环境和后续直接反馈。手机独立运行、可配置模型、多供应商、无资料先学与后补资料版优先等方向均来自明确的产品要求。

Codex 辅助阅读既有材料、实现 Python / SQLite 核心、Kotlin / Compose 客户端、Room 缓存与操作队列、进程内桥接和模型适配器，编写合成教材、测试及文档，并执行获授权的构建、模拟器检查和有限模型联调。AI 生成的代码与文档需要维护者理解、核验和维护，不能直接登记为参赛者的独立技术贡献。

## 反馈如何进入开发

用户直接指出了无材料问题不能解答、配置入口不明显、字号颜色影响理解、多供应商支持不足等问题。Codex 据此辅助修改实现，并用源码、隔离测试及实际可操作界面分别核对。

另有试用方提供的定性汇总：本人及 8 名同学使用手机体验，整体流畅但有小问题。没有补写未知日期、任务、设备型号、用时、评分或具体故障归属；开发过程中发现的失败不冒充这组同学的经历，也没有生成不存在的学习成效或性能成绩。

## 当前实现与核查边界

- 默认模式仍为固定合成案例规则。四种协议适配不等于任意服务商 API 都可直接使用，型号参数匹配也不是第三方服务能力探测。
- 通用答案和卡片明确无课程依据，课程引用检查只验证结构、原文位置及版本；模型不自动判断掌握，尚无两版答案自动语义一致性验证。
- 0.5.1 实际设备供应商目录为空，修改时间早于 0.5.0 构建；只读检查未找到新版或测试误清配置的证据，但具体清空原因未确定。未把隔离迁移通过写成实际配置保留，也未擅自恢复真实 Key。
- 旧电脑数据、手机本地数据与密钥不会自动跨设备同步。尚无账号认证、课程成员权限、OCR、语音或云端接续。
- 公开摘要不包含实际密钥、私有端点、原始数据库或个人报名材料。公开前的扫描针对已知值与常见模式，不等于完整生产安全审计。
