## 已发生的协作

- 用户确定“问迹”的项目方向、匿名要求、证据可追溯与资料变更失效规则，并要求在已有设计基础上推进开发，提供 MuMu 环境进行运行检查。
- Codex 读取既有设计材料后，辅助实现 Python / SQLite 本地服务、Kotlin / Compose Android 客户端、Room 本地保存和待同步请求队列。
- Codex 编写合成资源分配图材料和领域回归、HTTP smoke、Android 存储分块辅助测试，协助运行构建与本地验证。合成资料不是真实课堂采样或用户反馈。
- 在 MuMu 操作中实际发现快捷键被注入为不可见控制字符，旧后端曾接受这种内容为作答。辅助修复增加了控制字符及纯不可见内容校验，并新增回归；普通换行和 tab 保留，form feed 仅用作资料正文分页。新增回归又发现孤立 Unicode 代理字符曾导致 500，已改为输入错误。
- Codex 还协助检查旧作答确认入口、资料版本变更后的依赖状态、离线记录及重试行为。真实失败记录保留在私有开发工作区，公开仓库不复制原始数据库、状态快照或操作日志。
- 用户要求优化 UI 并准备公开开发预览；Codex 分工进行界面改进、复查、白名单源码导出与公开说明整理。各版本的实际视觉与发布检查见 VALIDATION.md。
- 0.3.1 复查中，Codex 发现待同步请求被拒绝会挡住当前状态获取，辅助修复并增加 7 项 JVM 回归；用户未被记作这些代码或测试的独立编写者。本轮同时完善本地交付脚本的私有文件排除、更新 README 的场景介绍与证据说明。
- 用户解锁宿主环境后，Codex 对 0.4.0 进行 MuMu 界面实查：无 ADB 反向转发，完成内置两页 PDF 导入、演示疑问保存、规则解释及原文位置展开；检查竖屏资料操作与先独立作答提示。CUA 粘贴及 BackSpace 输入再次注入控制字符，未提交有效作答，没有把此轮记录为完整学习流程通过。
- 实查发现横屏模型设置提交空配置后，错误藏在滚动底部。Codex 辅助完成 0.4.1-preview（versionCode 6）：将错误移至固定标题区域，并保留非密钥字段的旋转草稿；未保存密钥仍不持久化。离线构建、26 项 JVM 测试与 Lint 检查通过，安装后核对版本且无 ADB 反向转发。MuMu 横竖屏空配置错误立即可见，横屏滚动到底后仍可见；四协议菜单完整，Responses 协议草稿旋转后保留，取消后仍为规则模式。具体记录见 VALIDATION.md。
- 0.4.1 升级后资料与疑问保留，复习草稿已清空并显示待独立作答。Codex 整理了当前三页工作流与设置错误截图，没有将旧版图改标为新版。本轮未输入 API Key，密钥旋转行为只作代码检查；真实 API 调用为 0，计划书 PDF 未变、未重新排版。67 项 Python 与 4 项设备测试为 0.4.0 基线，本轮未重跑，也未修改共享学习核心。

## 当前实现限制

用户要求手机脱离电脑独立运行，并确认需要时可以联网。0.4 由 Codex 辅助将原 Python 核心通过 Chaquopy 内嵌进 APK，增加手机内配置、Android Keystore 加密、内置合成教材及禁止自动重发解释请求的恢复规则。新增桥接、配置与设备测试；实际通过范围和失败恢复见 VALIDATION.md。此次未用手机调用真实外部模型，未编造手机用户试用或实体设备成绩。旧电脑版数据保留，未做自动迁移。

0.4.0 的部分界面检查和 0.4.1 的设置反馈复测已在用户解锁后完成。0.4.1 旋转实测只覆盖协议草稿，未实际输入密钥。模拟器自动化输入的控制字符问题不能用作真实输入法兼容性结论；实体手机、软键盘遮挡、不同输入法及有效手动作答仍需独立检查。

默认解释器为固定合成案例规则；0.3 由 Codex 辅助实现四种可配置模型协议、服务端检索与引用校验、客户端单次确认，以及并发/中断/版本变化测试。用户明确要求多供应商接入，并于 2026-11-17 提供私有服务配置，授权进行真实模型联调。Codex 协助完成两条合成教学用例、同请求重放与来源修订失效检查；凭证仅用于本机配置，没有纳入公开仓库。该端点的小范围成功不能推广为全部供应商兼容或语义效果已验证。

没有账户认证或课程成员权限。词项匹配不是语义支持评估，参考关键点不是自动判题。模拟器检查不能被表述为实体手机、真实性能或真实学生学习效果测试。0.3 首次检查因宿主窗口无法激活而中止，用户解锁后完成横竖屏确认与取消、合成生成、引用和自测入口检查；保留此前失败记录，该组界面检查没有调用真实外部模型。
