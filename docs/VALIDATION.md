### 设备测试覆盖什么

测试使用隔离数据库、带 UUID 的偏好文件和 Keystore alias、合成凭证；模型传输通过手机内的临时模拟服务验证，不使用真实供应商额度。

- 离线两页 PDF 导入、引用位置、学习记录持久化、来源修订失效。
- 模型调用前确认、请求去重、不自动重发、配置或问题变化后的拒绝。
- 无资料通用卡作答与自评、导入资料零自动调用、课程资料版优先及旧答案/卡片/作答保留。
- 多供应商和多模型重启后持久化；只有当前供应商的 Key 注入引擎；各模型输出上限独立。
- 编辑一个供应商不借用另一供应商的 Key；修改地址必须重新输入 Key。
- 暂停、删除当前模型或供应商均不自动切换到另一家；暂停保留目录和密钥。
- 取消暂存不提交、陈旧版本拒绝覆盖、真实 v1 加密夹具迁移、AAD 篡改失败关闭。
- 注入一次 `commit=false` 后，原目录、加密 IV 与密钥恢复。
